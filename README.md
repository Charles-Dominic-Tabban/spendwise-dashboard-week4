# SpendWise Dashboard Shell

## Project Description
SpendWise is a modern and responsive financial dashboard designed to help users view and organize their monthly expenses.

This project was created as part of the PLP Week 4 CSS Layout assignment.

## Features
- Sidebar navigation menu.
- Dashboard header with user profile.
- Three financial summary cards.
- Six spending category cards:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Responsive layout for mobile screens.
- Light and dark themes.
- Hover and keyboard focus animations.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries

## Project Files
- `index.html` – Contains the dashboard structure and financial information.
- `style.css` – Contains the styling, layout, colors, responsiveness, and animations.
- `README.md` – Explains the project and its features.

## Layout Techniques
CSS Grid is used for the overall dashboard layout and financial cards.

Flexbox is used to arrange the sidebar navigation, header, profile, and card content.

Media queries make the dashboard responsive on smaller screens.

## Note
This project uses static financial information. JavaScript functionality is not required for this assignment.
